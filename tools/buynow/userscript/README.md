# TTM 유저스크립트 메모 (2026-10-16)

`ttm-autobuy.user.js` — Thai Ticket Major 이벤트 목록 페이지에서 지정 시각부터
새로고침하다가 XPath 요소가 `BUY NOW` 이면 클릭하는 Tampermonkey 스크립트.
현재 v1.3 (v1.2 원본은 git 이력 `3cea47f` 에 보관).

배경: Playwright 기반 `buynow` 는 사이트(Akamai)에서 `Access Denied` 로 차단됨.
이후 Aside(AI 에이전트) 지시문 방식과 이 유저스크립트 방식을 검토.

## 사용
1. 브라우저에 Tampermonkey 확장 설치 → 새 스크립트 → 파일 내용 붙여넣기 → 저장
2. `XPATH`, `START_TIME`(끝의 `+09:00` 유지 = 한국시간), 필요하면 `MAX_RELOADS` 수정
3. 로그인 후 이벤트 목록 페이지를 열어두면 HUD(우측 상단)에 카운트다운 표시

4. 클릭·10회 초과·Access Denied 로 **중지되면 그 탭에서는 다시 동작하지 않음** → 다시 하려면 탭을 닫고 새로 열기

## v1.3 변경 (v1.2 대비)
- **클릭 후 좌석/결제 페이지 강제 새로고침 제거**: 클릭 직전 탭(`sessionStorage`)에 중지 플래그 →
  다음 페이지에서는 스크립트가 즉시 종료. 또한 로딩이 끝났는데 공연 목록(`div.event-item`)이 없으면
  목록 페이지가 아닌 것으로 보고 새로고침 없이 종료 (강제 새로고침은 로딩 자체가 15초 넘게 안 끝날 때만).
- **새로고침 최대 횟수(`MAX_RELOADS`, 기본 10)**: 횟수를 `sessionStorage` 에 누적해 새로고침해도 유지, 초과 시 중지.
- **Access Denied 화면이면 즉시 중지** (계속 새로고침하면 차단이 길어짐).
- `START_TIME` 에 `+09:00` → PC 시간대와 무관하게 한국시간.
- document-start 에서 `<html>` 이 아직 없으면 HUD 가 문서 루트가 되어 페이지가 안 그려지던 문제 수정.
- 로컬 검증 (Chromium, 가짜 목록/좌석/차단 페이지):
  COMING SOON → 1+10회 로드 후 중지 / BUY NOW → 클릭 후 좌석 페이지에서 추가 로드 없음
  (v1.2 는 같은 상황에서 40초간 좌석 페이지 2회 강제 새로고침) / Access Denied → 1회 로드 후 중지.

## 검토 메모 (v1.2 기준, ~~취소선~~ = v1.3 에서 해결)
- ~~**결제/좌석 페이지에서도 동작함 (중요)**~~: `@match` 가 `thaiticketmajor.com/*` 전체라,
  클릭 후 넘어간 페이지에서도 스크립트가 다시 실행된다. 그 페이지엔 `div.event-item` 이 없어서
  15초(`WAIT_TIMEOUT`)마다 **강제 새로고침** → 좌석 선택 중 페이지가 날아갈 수 있음.
  → `@match` 를 이벤트 목록 페이지 URL 로 좁히거나, 클릭 시 `sessionStorage` 에 완료 플래그를 남기고 시작부에서 확인.
- ~~`doneKey` 는 만들기만~~ 하고 쓰지 않음 (`Date.now()` 라 매 로드마다 값도 바뀜) → 위 플래그로 대체.
- ~~`found` / `attempts` 는 새로고침마다~~ 초기화됨 → HUD 회차가 항상 `1회차`. 횟수 제한을 두려면 `sessionStorage` 에 저장.
- ~~**새로고침 횟수 제한 없음**~~: 1초 간격 무한 반복 → 접속 차단(Access Denied) 위험. 최대 횟수 또는 종료 시각을 둘 것.
- ~~`START_TIME` 에 시간대 표기가 없어~~ **PC 시간대 기준**으로 해석됨. PC 가 태국 시간대면 2시간 어긋남
  → `'2026-10-16T11:45:00+09:00'` 처럼 `+09:00` 을 붙이면 PC 설정과 무관하게 한국시간.
- PC 시계가 늦으면 그만큼 늦게 시작 → Windows `설정 > 시간 및 언어 > 지금 동기화`.
- XPath 의 `div[12]` 는 "목록의 12번째 공연 카드" — 목록 순서가 바뀌면 다른 공연을 누를 수 있음.
  (Aside 지시문 때는 `div[15]` 였음 — 공연마다 확인 필요)
- 사이트 약관상 매크로 금지 가능성, 본인 관람용으로만.
